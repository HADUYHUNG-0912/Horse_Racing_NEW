% ─── 2. Product Background ───────────────────────────────────────────
\subsection{2. Product Background}
\label{sec:background}
 
Horse racing is a competitive sport that involves multiple stakeholders — including race organizers, horse owners, jockeys, referees, and spectators — each requiring timely and accurate information to participate effectively. Traditionally, the management of horse racing tournaments has been carried out through manual processes, which are error-prone, time-consuming, and difficult to scale.
 
The \textit{Horse Racing Tournament Management System} is proposed to address these challenges by providing a centralized, digital platform that automates and streamlines the entire tournament lifecycle: from user registration and horse enrollment, through race scheduling and referee assignment, to result recording and leaderboard updates.
 
% ─── 3. Existing Systems ─────────────────────────────────────────────
\subsection{3. Existing Systems}
\label{sec:existing}
 
\subsubsection{3.1 Manual / Spreadsheet-Based Management}
 
\textbf{Description}: Many racing organizations currently rely on spreadsheets (Microsoft Excel, Google Sheets) and printed forms to track registrations, race schedules, and results.
 
\textbf{Drawbacks:}
\begin{itemize}[leftmargin=2em]
  \item No real-time synchronization — updates must be manually distributed to all parties.
  \item High risk of data entry errors and version conflicts.
  \item No role-based access control; sensitive data is exposed to unauthorized personnel.
  \item Difficulty generating automated leaderboards or performance statistics.
\end{itemize}
 
\subsubsection{3.2 Generic Sports Management Platforms}
 
\textbf{Description}: General-purpose sports management tools (e.g., SportyHQ, TeamSnap) provide basic scheduling and communication features for various sports.
 
\textbf{Drawbacks:}
\begin{itemize}[leftmargin=2em]
  \item Not designed for horse racing — lack domain-specific features such as horse profile management, jockey assignment, and race-specific refereeing workflows.
  \item Limited support for multi-role workflows (Horse Owner, Jockey, Race Referee, Spectator).
  \item Integration with race result hardware or official timing systems is typically not available.
  \item High licensing costs with features irrelevant to horse competitions.
\end{itemize}
 
% ─── 4. Business Opportunity ─────────────────────────────────────────
\subsection{4. Business Opportunity}
\label{sec:opportunity}
 
By centralizing the management of horse racing tournaments, the system enhances collaboration, improves communication among all stakeholders, and optimizes the workflow from race registration to result publication. The key business opportunities include:
 
\begin{itemize}[leftmargin=2em]
  \item \textbf{Efficiency gains}: Automating registration, scheduling, and result processing reduces administrative workload by an estimated 60\%.
  \item \textbf{Data accuracy}: A single source of truth eliminates duplication and ensures consistent, up-to-date information across all roles.
  \item \textbf{Fan engagement}: Real-time leaderboard and race schedule visibility enhances the spectator experience and can increase event attendance.
  \item \textbf{Scalability}: The platform can grow to support multiple concurrent tournaments and additional user roles without significant re-engineering.
  \item \textbf{Auditability}: A complete digital trail of all registrations, race results, and administrative actions supports compliance and dispute resolution.
\end{itemize}
 
% ─── 5. Software Product Vision ──────────────────────────────────────
\subsection{5. Software Product Vision}
\label{sec:vision}
 
\textbf{For} racing organizations and equestrian clubs \textbf{who} need a reliable and transparent platform to organize horse racing tournaments, the \textit{Horse Racing Tournament Management System} is a web application \textbf{that} provides end-to-end tournament management — from horse and jockey registration to real-time race results and leaderboard updates. \textbf{Unlike} manual spreadsheet-based processes or generic sports platforms, \textbf{our product} delivers a purpose-built, role-aware solution that serves Admins, Horse Owners, Jockeys, Race Referees, and Spectators within a single integrated system.
 
% ─── 6. Project Scope & Limitations ─────────────────────────────────
\subsection{6. Project Scope \& Limitations}
\label{sec:scope}
 
\subsubsection{6.1 Major Features}
 
\paragraph{6.1.1 Major Features for Admin}
\begin{itemize}[leftmargin=2em]
  \item FE-01: Login / Logout
  \item FE-02: Manage user accounts (create, update, deactivate)
  \item FE-03: Manage tournament information
  \item FE-04: Manage race schedule and race lanes
  \item FE-05: Assign referees to races
  \item FE-06: Publish results and update leaderboard
  \item FE-07: Send system notifications
\end{itemize}
 
\paragraph{6.1.2 Major Features for Horse Owner}
\begin{itemize}[leftmargin=2em]
  \item FE-01: Login / Logout
  \item FE-02: Register and manage horse profiles
  \item FE-03: Enroll horses in tournaments
  \item FE-04: View race schedule and results for owned horses
  \item FE-05: View leaderboard standings
\end{itemize}
 
\paragraph{6.1.3 Major Features for Jockey}
\begin{itemize}[leftmargin=2em]
  \item FE-01: Login / Logout
  \item FE-02: View and accept race invitations
  \item FE-03: View assigned race schedule
  \item FE-04: View personal performance history and rankings
\end{itemize}
 
\paragraph{6.1.4 Major Features for Race Referee}
\begin{itemize}[leftmargin=2em]
  \item FE-01: Login / Logout
  \item FE-02: View assigned race list
  \item FE-03: Enter and confirm race results
  \item FE-04: Flag incidents or disqualifications
\end{itemize}
 
\paragraph{6.1.5 Major Features for Spectator}
\begin{itemize}[leftmargin=2em]
  \item FE-01: Register / Login (optional)
  \item FE-02: View race schedule and tournament information
  \item FE-03: View real-time results and leaderboard
  \item FE-04: View horse and jockey profiles
\end{itemize}
 
\subsubsection{6.2 Limitations \& Exclusions}
 
\begin{itemize}[leftmargin=2em]
  \item \textbf{LI-1: Live timing hardware integration} — The current version does not integrate with physical race timing sensors or photo-finish equipment; results are entered manually by the Race Referee.
  \item \textbf{LI-2: Payment gateway} — Online betting, entry fee payments, and prize disbursements are out of scope for this release.
  \item \textbf{LI-3: Mobile native application} — Only a responsive web application is delivered; dedicated iOS/Android apps are not included.
  \item \textbf{LI-4: Third-party horse registry} — Integration with official national horse registries or stud-book databases is not supported in this version.
  \item \textbf{LI-5: AI/ML prediction features} — Automated race outcome prediction or ranking prediction based on historical data is deferred to a future release.
\end{itemize}
