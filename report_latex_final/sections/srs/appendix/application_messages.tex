\section{Application Messages}

This section lists standard messages used across the Horse Racing Tournament
Management System. Messages are grouped by feature and include a short type
and the text shown to users.

\subsection{Message Type Definitions}
\begin{itemize}
  \item \textbf{Inline} --- Displayed directly below a field or section (neutral information).
  \item \textbf{Inline (Red)} --- Displayed below a field when validation fails (error highlight).
  \item \textbf{Toast (Success)} --- Floating notification (green) shown after a successful action.
  \item \textbf{Toast (Error)} --- Floating notification (red) shown when an action fails.
  \item \textbf{Toast (Warning)} --- Floating notification (yellow) shown as a caution before an action.
\end{itemize}
