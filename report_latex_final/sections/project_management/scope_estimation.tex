\section{Scope \& Estimation}

To ensure the project is delivered successfully within the constraints of time and resources, the project scope has been broken down into a detailed Work Breakdown Structure (WBS). The WBS divides the Horse Racing Tournament Management System into 7 distinct modules, covering administrative tasks, core infrastructure, and functional components for various user roles.

Each work item is assessed for complexity (Simple, Medium, or Complex) based on the database interactions, business logic density, and interface requirements:
\begin{itemize}
    \item \textbf{Simple}: Basic CRUD operations, simple UI layouts, or minor configurations requiring 5 to 6 man-days.
    \item \textbf{Medium}: Standard functional features with moderate business logic (e.g., forms validation, standard data list with filters) requiring 7 to 8 man-days.
    \item \textbf{Complex}: Critical components involving advanced logic, multiple integrations, or strict constraints (e.g., conflict checking algorithms, two-step referee verification, real-time leaderboard calculations) requiring 9 to 15 man-days.
\end{itemize}
