CONTEXT

Đây là dự án báo cáo LaTeX làm việc nhóm. Agent đang sửa sai khi chèn toàn bộ ảnh và nội dung Screen Flow vào:

documents/software_requirement_specification.tex

hoặc

sections/srs/software_requirement_specification.tex

Điều này KHÔNG đúng với kiến trúc dự án.

KIẾN TRÚC LATEX CỦA DỰ ÁN

Dự án sử dụng mô hình:

main.tex
    ↓
documents/*.tex
    ↓
sections/**/*.tex
main.tex

Chỉ include 4 chương:

\include{documents/project_introduction}
\include{documents/project_management_plan}
\include{documents/software_requirement_specification}
\include{documents/software_design_description}
documents/*.tex

Các file trong thư mục documents/ chỉ là file điều hướng chương.

Ví dụ:

documents/software_requirement_specification.tex

Chức năng:

tạo chapter
tạo section lớn
include các file con

Ví dụ:

\chapter{Software Requirement Specification}

\input{sections/srs/product_overview}
\input{sections/srs/actors}
\input{sections/srs/usecase_description}
\input{sections/srs/flows/horse_owner_registration/screen_flow}

File này KHÔNG chứa:

hình ảnh
screenshot
screen flow
screen description
nội dung chi tiết của từng chức năng
QUY TẮC QUAN TRỌNG

Mỗi flow có thư mục riêng.

Ví dụ:

sections/srs/flows/
│
├── horse_owner_registration/
│   ├── screen_flow.tex
│
├── jockey_invitation/
│   ├── screen_flow.tex
│
├── race_scheduling/
│   ├── screen_flow.tex
│
└── race_result_ranking/
    ├── screen_flow.tex
VỊ TRÍ ĐÚNG ĐỂ CHÈN ẢNH

Tất cả:

ảnh Screen Flow
hình giao diện
screenshot
bảng Screen Description
mô tả Feature-Screen
nội dung của từng màn hình

PHẢI được đặt trong:

sections/srs/flows/<flow_name>/screen_flow.tex

Ví dụ:

sections/srs/flows/horse_owner_registration/screen_flow.tex
KHÔNG ĐƯỢC LÀM

❌ Không chèn toàn bộ ảnh vào:

documents/software_requirement_specification.tex

❌ Không đặt toàn bộ Screen Flow trong một file SRS.

❌ Không viết nội dung trực tiếp vào main.tex.

❌ Không gộp nhiều flow vào một file.

CÁCH LÀM ĐÚNG

Ví dụ:

% documents/software_requirement_specification.tex

\chapter{Software Requirement Specification}

\input{sections/srs/product_overview}

\input{sections/srs/flows/horse_owner_registration/screen_flow}

\input{sections/srs/flows/jockey_invitation/screen_flow}

\input{sections/srs/flows/race_scheduling/screen_flow}

Còn:

% sections/srs/flows/horse_owner_registration/screen_flow.tex

\subsection{Horse Owner Registration Screen Flow}

\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth]{figures/horse_owner_flow.png}
    \caption{Horse Owner Registration Flow}
\end{figure}

INSTRUCTION

Nếu cần thêm ảnh hoặc nội dung của một chức năng:

Xác định flow tương ứng.
Mở đúng thư mục flow.
Chèn vào file screen_flow.tex của flow đó.
Không chỉnh sửa main.tex.
Không chèn nội dung vào file SRS tổng.

Hãy giữ đúng kiến trúc:
main.tex → documents → sections → flow files.
